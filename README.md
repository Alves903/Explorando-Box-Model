# 📦 Explorando o Box Model no CSS

Projeto desenvolvido para praticar o Box Model no CSS, trabalhando propriedades como margin, padding, border, width e height. O site também utiliza centralização com Flexbox e personalização visual das caixas.

## 🚀 Tecnologias usadas
- HTML5
- CSS3

## 📚 O que foi praticado
- Width e Height
- Padding
- Margin
- Border
- Background-color
- Inspecionar elementos no navegador

## 🎨 Funcionalidades
- Caixas com estilos diferentes
- Alteração de tamanhos e bordas
- Margens personalizadas
- Caixa bônus centralizada

## 📁 Estrutura
```bash
index.html
style.css
```
